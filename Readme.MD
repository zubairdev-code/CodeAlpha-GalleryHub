# ✨ Lumière Gallery

A modern and elegant image gallery web application built with **HTML, CSS, and Vanilla JavaScript**.  
Lumière Gallery provides a premium visual experience with advanced gallery interactions, responsive layouts, image management, and smooth UI animations.

---

# 📸 Project Overview

Lumière Gallery is designed as a professional photography and image showcase platform featuring:

- Dynamic masonry gallery layout
- Interactive lightbox viewer
- Image upload system
- Search & filtering functionality
- Favourite image management
- Responsive modern UI
- Local storage persistence

The project focuses on delivering a luxury dark-themed user experience with smooth transitions and highly interactive components.

---

# 🚀 Features

## 🖼 Dynamic Masonry Gallery
- Responsive masonry grid layout
- Adaptive column system
- Smooth hover animations
- Elegant image overlays

---

## 🔍 Advanced Search System
Users can instantly search images by:
- Image title
- Category
- Description

---

## 🏷 Category Filtering
Built-in filtering system with multiple categories:

- Nature
- Architecture
- Portrait
- Abstract
- Travel
- Other

---

## ⭐ Favourite System
- Mark images as favourites
- Favourite-only gallery mode
- Persistent favourite state using LocalStorage

---

## 📂 Image Upload System
Supports:
- JPG
- PNG
- GIF
- WebP

Features:
- Drag & Drop upload
- Multiple image upload
- Live preview thumbnails
- Upload progress indicator

---

## 🔦 Interactive Lightbox Viewer
Includes:
- Fullscreen image preview
- Previous / Next navigation
- Zoom functionality
- Download image option
- Favourite toggle
- Keyboard shortcuts support

---

## 📱 Fully Responsive Design
Optimized for:
- Desktop
- Tablet
- Mobile devices

The gallery automatically adjusts layout based on screen size.

---

## 💾 Local Storage Persistence
All uploaded images and favourites are stored in the browser using:
- LocalStorage API

This allows the gallery state to remain saved even after refreshing the page.
